## 概览

- **适合**：按分类看有什么、按文件名搜索、**进某个目录浏览**（含排序与宫格/列表切换）、
  读各类占用与剩余空间、进「最近删除」看还有多少天可恢复。
- **不适合**：删除文件、清空回收站、空间清理（不可逆，只指路）、判断剩余空间（`lw_storage` 更快）。

一句话结构：底部分区是 **最近 / 文件 / 跨设备访问**；「最近」页是分类网格（分类卡的文字在子节点 `text` 上，
卡片本身没有 desc）；进某个存储位置才是**目录浏览页**（工具行最全）。

## 什么时候不要用我

- 已知路径的读写、列目录、找文件 → 直接用文件工具（read / glob / bash），不必进这个应用
- 只想知道还剩多少空间 → `lw_storage`
- 删除、清空最近删除、空间清理 → 不可逆，列清单等主人确认

## 前提

- 无障碍（屏幕读取）权限已授予。
- 实测环境：vivo V2417A / Android 16，2026-10-11 走查；屏幕 1260×2800。
- 首次进「手机存储」会弹一条提示「"手机存储"即为"/storage/emulated/0" 或 "/sdcard"路径。」，
  关掉后才能看到目录内容（提示框 id=tips_img desc=关闭）。

## 入口

- 包名 `com.android.filemanager`，组件 `.FileManagerActivity`。
- 冷启动落「最近」页。

## 流程

### 一、搜索一个文件（最快）

1. 打开文件管理（落在「最近」页）。
2. 点搜索框，**覆盖式写入**文件名关键词（`lw_type(replace=true)`）。
3. 判据：出现匹配结果列表（含路径/大小/时间）。
4. 点结果可由对应应用打开；只想知道在哪时读到路径即可。

### 二、按分类看有什么

1. 在「最近」页读分类卡的数量（`text` 子节点的数字）。
2. 点目标分类卡（如「安装包」）→ 判据：进入该分类列表，行内是文件名与大小/时间。
3. 需要时用列表内的排序/宫格按钮整理视图。

### 三、进某个目录浏览（含排序与新建）

1. 「最近」页 →「存储位置」→ 点「手机存储」。
2. 首次会弹路径提示 → 点 `tips_img`(desc=关闭) 关掉。
3. 判据：顶栏标题变成「手机存储」，工具行出现「系统模式 / 按名称：A到Z / 新建 / 切换宫格」。
4. 读文件行（`item_root_view` 内的文件名与大小）；点目录行继续进下一级，BACK 返回上一级。
5. 要搜索当前目录内容：点顶栏 desc=搜索（比滚动快）。

### 四、读存储占用

- 总量与可用：「最近」页「手机存储」行的 summary（如「可用 65.87 GB/256 GB」）
  与空间条上的「已用 190.13 GB」——**两个数相加应≈总量**，不自洽就别报。
- 各分类占用：分类卡上的数量/大小。
- 更稳的做法：直接 `lw_storage`（数字来自系统，不受界面刷新影响）。

### 五、看最近删除（还能不能救）

1. 「最近」页 → 点「最近删除」（summary 是项数）→ 判据：进入最近删除页。
2. 每行 `tv_subinfo` 里有**「剩余 N 天」**——这是判断「还来不来得及恢复」的唯一依据。
3. 排序用 `sort_spinner`（默认「按剩余时间：新到旧」）。
4. 恢复操作本技能不代做（见危险步骤）。

## 已知坑

- **分类卡没有 desc**：卡片本身在树里是无描述的 `LinearLayout`，文字在子节点 `text` 上；
  `lw_tap(text="安装包")` 通常能命中子文本（内嵌在可点卡片里），命不中就先拿卡片矩形再按坐标点。
- **搜索框占位是「搜索」**：直接输入会连成「搜索xxx」，必须覆盖模式。
- **进「手机存储」先弹提示**：不关掉它，树里只有提示框（实测只剩 10 个节点），会误判「这页读不到」。
- **底部分区「文件」在虚拟屏上没切换成功**（2026-10-11：按名字与按坐标各试一次，页面无变化）——
  需要目录浏览时走「存储位置 → 手机存储」这条路，别依赖那个分区。
- **「更多,有新消息」这个 desc 带后缀**：`lw_tap(text="更多")` 匹配不上，要用完整 desc。
- **回收站保留期**：每行的「剩余 N 天」会变，过期即永久删除；结论要带读取时间。
- **云盘 / iCloud 是联网项**：点开涉及账号与网络，非必要不点。
- **「空间清理」是危险入口**：会批量删缓存与文件。

## 验证

- 找文件：结果列表出现目标文件名，且大小/时间与预期相符。
- 磁盘自洽：已用 + 可用 ≈ 总量（并用 `lw_storage` 对账）。
- 最近删除：项数与「最近」页 summary 的数字一致。

## 危险步骤

> ⚠️ **危险**：以下动作**执行前必须列出「哪些文件、多少项、多大」并等主人确认**：
> 1. 目录浏览页里对文件/目录的**删除**（进最近删除，尚有挽回余地）；
> 2. 最近删除页的 **删除 / 清空**（永久，不可恢复）；
> 3. 「空间清理」（批量删缓存与文件）；
> 4. 多选之后的**移动**（会把文件挪走，主人可能找不到）。
> 主人自己的测试文件（如 Agent 为验证流程新建的）验证完当场删掉，并在汇报里说明删了什么。

## 工具映射（本机 LittleWhale）

`lw_launch("com.android.filemanager")`、`lw_ui` / `lw_ui_dump` 读树、
`lw_tap(text=…)` 按文本/desc 点、`lw_type(replace=true)` 写搜索框、`lw_swipe` 翻列表、`lw_key(BACK)` 返回；
路径与大小的最终判断优先用 `lw_files` / `lw_storage` / read / glob，别只信界面数字。
