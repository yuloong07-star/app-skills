## 概览

- **适合**：新建一次性日程（标题 + 开始/结束时间 + 备注）、按关键词搜索已有日程、查看某天安排。
- **不适合**：删除别人的共享日程、修改系统账号同步设置。

最大的坑是**时间选择控件**：vivo 日历的日期/时间用滚轮选择，滚轮在控件树里不可点按，
必须用拖动（滑动）来改值，且拖动前后要留出约 1 秒再读屏。

## 前提

- 应用已安装（包名 `com.bbk.calendar`）。
- 已授予屏幕读取权限。
- 需要写入的日历账号已存在；若日历不可写，应用会提示先登录账号。

## 入口

- 包名：`com.bbk.calendar`
- 冷启动进入月视图主页。
- 主页右下角悬浮按钮 = **新建日程**；顶部有「今天」「搜索」等入口。
- 视图切换：月 / 周 / 日；另有「课程表」视图（见已知坑）。

## 关键控件

| 位置 | 控件 | 定位方式 |
| --- | --- | --- |
| 主页右下角 | 新建日程 | 悬浮按钮，描述「新建日程」/「＋」 |
| 新建页标题行 | 标题 | 文本「添加标题」的输入框 |
| 新建页 | 开始/结束时间 | 文本显示当前时间；点击展开滚轮 |
| 滚轮 | 日期列 / 小时列 / 分钟列 | 控件树里常暴露为 `SeekBar`（如 `not_allday_col2/3/4`），其文本即当前值 |
| 新建页顶部 | 天气条 | 显示当日天气，可作第二路信息源 |
| 新建页右上 | 保存 | 文本「保存」 |

## 流程一：新建一条日程

1. 打开日历，停在月视图。
   - 判据：顶部显示当前年月，日历网格可见。
2. 点击「新建日程」。
   - 判据：进入编辑页，顶部是标题输入框，下面是起止时间。
3. 点击标题框，写入标题。
   - 判据：标题行显示写入的文字。
4. 设定开始时间：点击开始时间展开滚轮，然后**拖动**对应列到目标值。
   - 判据：等待约 1 秒后读控件树，时间文本已是目标值（不要只拖动一次就假定成功）。
   - 日期列、小时列、分钟列是三个独立的滚动区，逐列改。
5. 同样方式设定结束时间。
6. 可选：填写备注/地点。
   - 地点通常是 POI 选择器，需要输入后从候选里选，不要指望输入的文字就是地点。
7. 点击「保存」。
   - 判据：返回月视图，目标日期格子里出现新日程的标题。

## 流程二：找到并修改已有日程

1. 在主页点击「搜索」。
   - 判据：进入搜索页。
2. 输入日程标题关键词并搜索。
3. 点击结果行打开详情。
   - 判据：详情页显示标题与时间，右上角有编辑/删除入口。
4. 点编辑 → 按流程一的方式改字段 → 保存。
   - 危险动作：**删除**请按下节处理。

> ⚠️ **危险**：删除日程不可恢复（部分账号有回收站但不保证）。
> Agent 不得自行删除，必须先把"将删除哪一条（标题 + 时间）"报给用户并得到明确确认。

## 已知坑

- **时间滚轮不吃点按**：日期/时间滚轮只能拖动改值；点按无效。
  拖动起止点都要落在该列的矩形内，改完等约 1 秒再看结果。
- **课程表只有周一到周五**：想安排周末的课，不要用「新建课程」，
  周末列不存在，建了也不显示；改用主页「新建日程」，标题写课程名、备注写清是补哪天的课。
- **控件树滞后**：改完时间立刻读屏会读到旧值，先等再读，否则误判为"没动"。
- **列表滚不动**：日程列表用滚动查找容易失败，优先用「搜索日程」直达。
- **窗口可能消失**：在虚拟屏上操作时应用窗口偶发消失，重新拉起应用即可，不必重建环境。
- **地点只能选 POI**：直接输入文字后不选候选，保存时地点会为空或报错。

## 验证

- 保存后回到月视图，**目标日期格子里能看到该日程标题**才算成功。
- 再补一路证据：用「搜索」按标题搜一次，能搜到且时间正确。
- 只看到"已保存"提示不算。
