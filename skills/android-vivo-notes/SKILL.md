## 概览

- **适合**：新建/追加/查找笔记，浏览与新建文件夹，切换底部四个分区（笔记/待办/文档/我的）。
- **不适合**：批量删除、账号与云同步操作（涉及数据不可逆，须交回用户）。

首页是双栏：左侧文件夹抽屉 + 右侧笔记列表。控件文本丰富，优先按文本或描述点。

## 什么时候不要用我

- 往标题固定的专门笔记里写数据（如「健康日报」）→ 用 health-daily-report 技能，它自带日期过滤与写入流程
- 要把文件内容原样读出来再答复 → 直接用文件工具读，不必进笔记应用

## 前提

- 已授予无障碍（屏幕读取）权限；无需登录即可本地使用。
- 长文**一次性整段写入**，不要分段追加（分段写会被后段覆盖）。

## 入口

- 包名 `com.android.notes`，启动组件 `com.android.notes/.Notes`，冷启动直达首页。
- 首页结构（实测控件树）：
  - 顶部：标题「全部」+ 副标题「115篇笔记」；按钮 desc=`搜索`、desc=`排序`。
  - 左侧抽屉 `recycler_view`：「全部」「未分类」，`edit_start`（desc=编辑文件夹）、`new_folder`（desc=新建文件夹），下方文件夹行 `item_root`（title=id=title）。
  - 右侧列表 `note_list`：每条含 `note_title`（标题）、`first_content`（首行摘要）、时间。
  - 右下角新建按钮 `add_icon_layout`（**纯图标、无文本无描述**，矩形约屏幕右下区域）。
  - 底部 tab：笔记 / 待办 `tab_todo` / 文档 `tab_word` / 我的 `folder`（均有 desc 可按名点）。

## 流程一：新建一篇笔记

1. 打开应用，判据：出现笔记列表与右下角新建按钮。
2. 点新建按钮（无文本，用坐标点其实测有效；若坐标无效改截屏定位）。
   - 判据：进入编辑页，出现 `title_edit_text`。
3. 编辑页结构（实测）：顶栏 `back_btn`(返回) / `iv_undo`(撤销) / `iv_redo`(恢复) / `finish_edit`(完成)；`title_edit_text` 标题框；`edit_time` 自动显示当前时间；`count_word` 实时字数；`note_folder_text` 所属文件夹（默认「未分类」）；`line_edit_text` 正文框；底部工具条（小V写作/素材效果/文本编辑/段落编辑/待办事项/拍摄或选择图片/添加附件）。
4. 点 `title_edit_text` 输入标题，再点 `line_edit_text` 输入正文。
   - **两个输入框必须分别点**，否则内容会串位。
5. 点 `finish_edit`（完成）。
   - 判据：返回列表，`note_list` 首条 `note_title` 即新标题。

## 流程二：查找标题为 X 的笔记

1. 点顶部 desc=`搜索` → 判据：进入搜索页。
2. 输入关键词（输入框有占位提示时用覆盖模式写入）。
3. 点结果条目 → 判据：进入编辑页，标题一致。
4. 搜索为空时：返回首页在「全部」列表滚动翻找后再下结论。

## 流程三：往已有笔记追加一段

1. 按流程二打开目标笔记。
2. 点 `line_edit_text` 把光标定位到文末（控件树读不到光标，先看画面确认）。
3. 先换行再整段写入追加内容 → 点完成。
4. 验证：重新打开该笔记，末尾是新内容且旧内容完整（对比追加前首尾文字）。

## 流程四：新建文件夹

1. 首页左侧抽屉点 `new_folder`（desc=新建文件夹）。
2. 输入名称确认 → 判据：抽屉 `我的文件夹` 分组下出现新行。

## 已知坑

- **双输入框串位**：标题与正文是两个独立 EditText，必须分别点后写入。
- **占位提示文字**：空输入框会显示提示文案，普通输入会连成「提示+新内容」，用覆盖模式。
- **字数校验**：`count_word` 的数字约为实际字符数的九成，可作写入量的快速核对。
- **列表刷新**：保存后偶发 1 秒延迟才上列表，等约 1 秒再读树，否则误判未保存。
- **新建按钮无文本**：坐标是唯一路径，坐标失灵时先截屏重新量取（不同分辨率别照抄）。
- **滚动**：控件树滚动动作在个别 ROM 失效，优先用搜索直达。

## 验证

- 保存后**重新进入笔记能读到内容**才算成功，「已保存」提示不算。
- 追加场景必须回读并比对旧内容未丢。
