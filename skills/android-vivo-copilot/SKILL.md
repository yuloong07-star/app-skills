## 概览

- **适合**：把一句自然语言的系统指令交给小V办（实测「设置明天早上6点40的闹钟」直接生成并开启）、
  问手机操作问题、浏览智能体广场与「我用过的智能体」、发起「深度研究」任务。
- **不适合**：账号、支付、验证码、隐私授权（一律不代发）；能用 `lw_*` 一遍做完的事（绕道更慢）。

三个要点：**主体内容是 WebView**（回答与卡片读不到控件树，只能截图 + OCR）；
**输入框 `et_chat_input` 写得进中文**；**发送键要按坐标点**（实测 `iv_chat_send` 无 desc）。
另外「说做了」不等于做了——**必须去目标应用回读**。

## 什么时候不要用我

- 能直接用 lw_* 工具一次做完的（读状态、点按钮）→ 自己做，别绕道
- 要设闹钟 / 日程 / 提醒 → 用 android-vivo-clock、android-vivo-calendar（可控、可回读）
- 涉及账号、支付、验证码、隐私授权 → 不代发
- 要精确数值或严格格式的结果 → 小V 的回答是自然语言，OCR 读回来可能有偏差

## 前提

- 无障碍（屏幕读取）权限已授予；小V 已开启可用。
- 实测环境：vivo V2417A / Android 16，2026-10-11 走查；屏幕 1260×2800。
- **主体是 WebView**：`WebView` 节点的矩形实测是 `[0,0][0,2800]`（零宽），正文一律读不到树。

## 入口

- 包名 `com.vivo.ai.copilot`；启动组件 `.transfer.EmptyLauncherActivity`，自动转
  `.business.home.HomeActivity`。
- 冷启动落首页（标题「蓝心小V」）。

## 流程

### 一、让小V执行一条系统指令

1. `lw_launch(displayId, "com.vivo.ai.copilot")`；判据：标题「蓝心小V」、底部出现 `et_chat_input`。
2. 点 `et_chat_input`，写入完整的一句话指令（写清对象与数值，例如「设置明天早上6点40的闹钟」）。
3. 点发送：先 `lw_ui` 找发送键矩形，**按坐标点**（`iv_chat_send` 无 desc）；
   判据：回读输入框已清空。
4. 等 2–5 秒，**截图 + OCR 读回答**（WebView 无控件树）。
5. 若回答说已执行，**必须去目标应用交叉验证**（如打开时钟看闹钟是否真的出现）——
   小V 说做了不等于真做了，以目标应用回读为准。

### 二、只提问不执行

同上一到三步，最后把 OCR 读到的回答原样转述，不加戏、不替它补充没说的结论。

### 三、翻侧边栏（对话记录 / 智能体 / 深度研究）

1. 点左上 desc=更多 → 判据：左侧抽屉出现（有「探索发现」「智能体广场」两个大按钮）。
2. 点目标项（我的对话记录 / 我用过的智能体 / 我的深度研究任务）。
3. **实测有的项点了没反应**（如「我的对话记录」），此时改用底部「下滑查看最近对话」或直接 BACK 收起抽屉。

## 已知坑

- **正文读不到树**：`WebView` 是零宽节点，回答、推荐卡、智能体列表都要截图/OCR。
  文字多时截全屏或分段读；`lw_ocr` 可用（本机 2026-10-11 复测可用）。
- **发送键无 desc**：`iv_chat_send` 只能按坐标点；点后**用「输入框是否清空」判断发没发出去**。
- **左上那个 desc=更多 是侧边栏**，不是设置；真正的设置/更多在右侧无描述的三个 Button 里（未验证）。
- **侧边栏部分项点不动**（实测「我的对话记录」点击无变化）——不要反复点，换路径。
- **执行结果要落地验证**：小V 的回复是「声称」，回目标应用读一遍才算证据。
- **会消耗额度**：每次对话都消耗小V 的额度，能用工具做的不要发给它。
- **输入框占位**：「点击输入或按住说话」是占位文字，普通输入会连起来，用覆盖模式写入。
- **首页整块是横向 ScrollView**（`root_drawer_container`），抽屉与主页在同一个横向容器里，
  读树时右边会出现 x 超过屏宽（负值或 >1260）的节点，属正常。

## 验证

- 执行类：**目标应用回读到新条目**（如时钟里出现该时间的闹钟）才算成功。
- 问答类：截图读出的回答与转述一致。
- 发送成功：输入框清空 + 屏幕上出现自己那句话。

## 未验证清单（2026-10-11 走查范围之外）

- 右侧三个无名 Button 的功能（可能是历史/设置/清空）。
- 「智能体广场」「探索发现」「我的深度研究任务」「新建对话」「前往创建任务」的落地页。
- 对话页（发过消息之后）的结构、语音输入、附件与拍照入口、深度研究任务的状态页。
- 推荐问题点击后的对话形态。
- 小V 的各条系统指令实际能覆盖哪些设置（本技能只以时钟为例记录过一次实测）。

## 危险步骤

> ⚠️ **危险**：小V **能真的改动系统设置**（网络、声音、闹钟、亮度…），也可能代为操作设备。
> 执行前把**要发的原话**报给主人过目，尤其是：断网/开热点、账户与隐私类、卸载与清理类、
> 任何涉及支付或验证码的指令——**后两类一律不代发**。
> 发出去之后必须去目标应用回读结果，不拿小V 的「已完成」当结论。

## 工具映射（本机 LittleWhale）

`lw_launch("com.vivo.ai.copilot")`、`lw_ui` 读结构层、`lw_type` 写中文、
发送键 `lw_tap(x=…, y=…)` 按坐标点、`lw_screenshot` + `read_image` / `lw_ocr` 读回答、
`lw_key(BACK)` 收抽屉。
