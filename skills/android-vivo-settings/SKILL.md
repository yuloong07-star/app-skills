## 概览

- **适合**：读系统当前状态（开关、存储、版本）、改常规开关、**找某个设置项在哪一页**、进二级页改参数。
- **不适合**：恢复出厂、清除数据、改密码/指纹、账户解绑、卸载或停用应用（一律只指出入口、不代点）。

三条主线：**首页行**（title + summary，整行可点）、**搜索直达**（首页搜索框，一次到二级页，找设置项最快的路）、
**二级页**（结构同上，页标题即设置项名，左上角固定有 desc=返回）。

## 什么时候不要用我

- 亮度 / 屏幕超时 / 自动旋转 / 字体缩放 → `lw_system` 直接读写，比进设置页快且不易误触
- 蓝牙 / 移动数据 / WiFi / 飞行模式的开关状态 → `lw_net` 直接读
- 存储总量与剩余 → `lw_storage` 直接读数字
- 只是问「某个应用自己怎么设置」→ 进那个应用，不在系统设置里

## 前提

- 无障碍（屏幕读取）权限已授予；设置页在自建虚拟屏上可正常落窗（实测）。
- 实测环境：vivo V2417A / Android 16，2026-10-11 走查。
- 屏幕 1260×2800；下文矩形只作理解用，实操一律从 `lw_ui` 实时取。

## 入口

- 包名 `com.android.settings`，落 `com.android.settings/.homepage.SettingsHomepageActivity`。
- 冷启动直达首页（标题「设置」）；首页可纵向滚动，首屏只显示到「指纹、面部与密码」。

## 控件速查表

**通用（每页都成立）**

| 控件 | id / desc | 动作 | 判据 |
| --- | --- | --- | --- |
| 返回 | `originui_vtoolbar_navigation_view_btn_rom14_0` desc=返回 | 点 | 回上一页（系统 BACK 等效） |
| 页标题 | `originui_vtoolbar_normal_title_rom14_0` | 读 | 即当前设置项名，「进对页没有」全靠它 |
| 设置行 | 行内 `title` + `summary` | 点 title 文本 | 进二级页或触发行内开关 |
| 行内开关 | 行上的 `Switch` | 读 checkable / 点 | 状态以 checkable 与 summary **两处一致**为准 |

**首页**

- 搜索框 `vigour_search_edit`（占位文字就是「搜索设置项」，**写入必须覆盖**）；
  有内容时出现 `vigour_search_clear_image` desc=清空，右侧 `vigour_search_right_btn` 文本「取消」。
- 账号卡 `account_category`（摘要「账号、云服务、查找设备等」）。

**搜索结果页**：`search_list_view`，每条 = `title`（设置项名）+ `subtitle`（**所在路径**，如「运存与存储 > 运行内存」）。
路径那一行很值钱：它能直接回答「这个设置项在哪」。

**手机存储（运存与存储）**：`title`「手机存储」+ `summary`「总空间 256 GB」；
`chart_summary_used`「已用 x」+ `chart_summary_available`「可用 y」；
九个分类行（图片/视频/音频/文档/安装包/压缩包/应用/系统/其他，右侧 summary 是占用）；
按钮 `vbtton_view` desc=空间清理；行「运行内存」summary 形如「16 GB + 16 GB」。

**显示、亮度与护眼**：`light_mode_layout` 浅色模式 / `dark_mode_layout` 深色模式；
「定时切换」（summary 如「日落时切换为深色」）；「深色模式设置」；亮度 `seek_bar`（滑杆，拖动改值）；
`Switch` desc=自动调节屏幕亮度；「智能调节应用亮度」（summary=已开启）；「悦目护眼」。

**声音与振动**：三个单选卡 `ring_mode_layout` 响铃 / `vibrate_mode_layout` 振动 / `mute_mode_layout` 静音
（**RadioButton 的 checked 就是当前档**）；四条 `ProgressBar#seek_bar`，desc 分别是 媒体/铃声/通知/闹钟；
「音量键调整」（summary=媒体）；「应用音量单独调节」；`Switch` desc=「听筒大音量模式…」；「专注模式」。

**应用**：六行 —— 应用管理 / 应用分身 / 默认应用 / 后台近期应用 / 系统应用设置 / 系统应用找回，
外加推荐区「权限管理」（text 可点）。

## 流程

### 一、用搜索直达某个设置项（首选）

1. 点 `vigour_search_edit`（或 desc=搜索设置项）→ 判据：输入框获得焦点、右侧出现「取消」。
2. `lw_type(replace=true)` 写入关键词（中文可以）→ 判据：`search_list_view` 出现结果，
   每条带标题与**路径**（如「隐私 > 权限管理」）。
3. 搜不到就换一个更短的关键词再搜（设置项名与直觉用词常不一致，「存储」比「容量」好用）。
4. 点结果行 → 判据：顶部标题变成该设置项名。
5. 改完用 BACK 逐级退回。

### 二、读一个开关的当前状态

1. 找到目标行（按 `title` 文本）。
2. **读 `Switch` 的 checkable，同时读 summary 文字**（首页 WLAN/蓝牙形如「已关闭/已开启」），两处一致才下结论。
3. 只想读不想改就到此为止，别顺手点。

### 三、改一个开关

1. 先**记住原状态**（读上一流程）。
2. 点该行（或行内 Switch）→ **等约 1 秒**再回读 checkable + summary。
3. 判据：两处都变成目标值，**不以点击返回值为准**。
4. 不是主人要求长期生效的，改完把不需要的改回原值，并在汇报里说明改了什么、原来是什么。

### 四、读设备状态（存储/版本/内存）

- 存储：首页搜索「存储」→「手机存储」→ 读 `summary`（总空间）与 `chart_summary_used/available`；
  更省事的是直接用 `lw_storage`。
- 版本：搜索「关于本机」→ 该页读版本号。
- 运行内存：手机存储页底部的「运行内存」行。

### 五、进二级页改参数

1. 点首页行 title → 判据：顶部标题变成该二级页名。
2. 页内结构同首页（title + summary + 可点的行/Switch/滑杆）。
3. 滑杆类（亮度、音量）用 `lw_swipe` 在 `seek_bar` 矩形内左右拖动，**拖完等约 1 秒再读**。

## 已知坑

- **搜索框占位文字**：占位就是「搜索设置项」，直接输入会连成「搜索设置项存储」，必须 `replace=true`。
- **结果里的「路径」要看清**：同一设置项常有多个条目（系统本体 + 手机管家 + 小V建议），
  按 subtitle 挑系统本体那条，否则会跳进第三方应用的页面。
- **开关状态要等**：点完立刻读会读到旧值（实测多次），等约 1 秒。
- **首页很长**：首屏只到「指纹、面部与密码」，下滚还有电池、系统升级、关于本机等；没找到先滚再下结论。
- **同名文本多**：`lw_tap(text="蓝牙")` 会命中多处（首页行、搜索结果标题），必要时先 `lw_ui` 拿矩形再按坐标点。
- **虚拟屏上坐标点按不可靠**（2026-10-11 实测）：没有名字的控件按坐标点可能「返回成功但无变化」，
  改用按名字点，或退用系统键 `DPAD_DOWN` + `ENTER`。
- **页面标题是判据**：每次进二级页都读一次 `originui_vtoolbar_normal_title_rom14_0`，别凭上一步的点击结果猜自己在哪。
- **有的行点 title 命中率低**：点不通就点该行矩形中部。

## 验证

- 读状态：Switch 的 checkable + summary 两路一致。
- 改设置：改后重读两处都变了才算成功（必要时重新进入该项）。
- 存储数字：已用 + 可用 ≈ 总空间 则该页自洽（与 `lw_storage` 对账更稳）。

## 危险步骤

> ⚠️ **危险**：以下入口**只指路、不代点**，由主人亲自操作：
> **恢复出厂设置 / 清除所有数据 / 清除缓存分区**、**改锁屏密码与指纹、面部**、**账户与云服务解绑**、
> **卸载或停用应用**（含系统应用设置里的停用）、**系统升级**（会长时间占机）、
> **空间清理**（批量删缓存与文件）、**OTG 存储的格式化**。
> 主人明确要求动其中某一项时，先把「点哪一行、会发生什么、是否可逆」说清楚再动手。
