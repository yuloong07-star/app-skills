## 概览

- **适合**：读相册与分类的数量、进某个相册、**看单张照片的日期与详细信息、分享/编辑/收藏/删除入口**、
  找「最近删除」并按剩余天数判断能否恢复。
- **不适合**：改图（用生图/改图技能）、批量整理、清空回收站（不可逆，只指路）。

一句话记住三件事：**照片网格是自绘的**（控件树里读不到照片，只能截图看）；
**「相册」tab 的结构层可读**，而且每张相册卡的 desc 就是「名称,数量」；
**照片查看器的工具栏全部可按名字点**（desc 齐全）。

## 什么时候不要用我

- 要把照片改样子（换背景、去物体、改风格）→ 用 dsh-imagegen-edit
- 问题只是「我屏幕上这张图是什么」→ 直接截屏看，不必打开相册
- 只想把一张图存进相册或跳到某张图 → 那是 `lw_image op=album` 的活
- 清理建议、清空最近删除 → 不可逆，列清单等主人确认

## 前提

- 无障碍（屏幕读取）权限已授予。
- 实测环境：vivo V2417A / Android 16，2026-10-11 走查；屏幕 1260×2800。
- 相册首页是四个分区：**照片 / 相册 / 推荐 / 搜索**（底部 `bottomBar`，每个分区是带 desc 的 FrameLayout）。

## 入口

- 包名 `com.vivo.gallery`，组件 `com.android.gallery3d.vivo.GalleryTabActivity`。
- 冷启动落到上次停留的分区（实测会停在「相册」或「照片」，**别假设是哪一个，先读标题**）。

## 流程

### 一、读相册与数量（最常用，只读）

1. `lw_launch(displayId, "com.vivo.gallery")` → 点底部 desc=相册。
2. 读每张相册卡的 desc（格式固定「名称,数量」，如「截屏,103」）——**这就是增删的断言**。
3. 楼层不止一屏：`lw_swipe` 向上拖动（起点终点都落在楼层区），继续读。
4. 汇报数量时说明读取时间；「全部项目」的数字是相册总数。

### 二、进某个相册看照片

1. 点该相册卡（按 desc 或按 `title` 文本）。
   判据：顶栏标题变成相册名，右上出现 desc=选择、desc=更多。
2. 照片网格**没有控件树**：`lw_screenshot` + `read_image` 看画面（连拍取最清晰一帧）。
3. 返回用 desc=返回 或系统 BACK。

### 三、看单张照片的信息 / 分享 / 编辑

1. 在网格里点一张照片 → 判据：进查看器，顶栏出现日期与时间，底部出现四个按钮。
2. 读日期：`originui_vtoolbar_normal_title_rom14_0`（如「昨天」）+ `..._sub_title_...`（时间）。
3. 要详细信息：点 desc=详细信息 → 读弹窗里的路径、大小、分辨率（这是判断「照片到底存在哪」的正路）。
4. 分享 / 编辑 / 删除：点底部对应按钮（删除见危险步骤）。
5. 返回退回网格。

### 四、找回收站（最近删除）

1. 相册分区 → 向下滚动到**「其他」楼层**（在智能分类之后）。
2. 点「最近删除」行（summary=数量）→ 判据：进入最近删除页，标题「最近删除」。
3. 要恢复某张：点它进查看器 → 点 desc=恢复。
   判据：该条从最近删除消失，原相册数量 +1（两处对账）。
4. 归档天数：最近删除里的条目带剩余天数（本机实测相册的最近删除保留期以页面提示为准）。

### 五、搜索（人物 / 地点 / 历史词）

1. 点底部 desc=搜索 → 判据：出现「最近搜索」与历史词标签。
2. 直接点历史词标签（desc=词）即可复搜；点 desc=删除 可清历史。
3. 人物/地点区各带「更多」；人物与地点来自系统识别，数量仅供参考。
4. 要打字：搜索框**不在控件树里**，先按坐标点它（屏幕左上区域），再 `lw_type`；
   打不进去就改用「最近搜索」里的词——不要跟自绘输入框较劲。

## 已知坑

- **照片流与相册网格都是自绘**：控件树里只有结构层，找不到任何一张照片。
  凡涉及「照片本身」的判断（拍的什么、右下角有没有水印）一律截图看，别在树里找。
- **数量就在 desc 里**：相册卡 desc=「名称,数量」，比数格子可靠得多，可作增删断言。
- **照片分区顶栏三个按钮没有 desc**（2026-10-11 实测只有三个无描述的 Button），只能用坐标点；
  能不进「照片」分区就不进。
- **相册分区的楼层很长**：「其他」（清理建议、最近删除）在智能分类之下，要滚 3 屏左右才到。
- **「最近删除」不在第一屏**：先滚到「其他」楼层，别看首屏没有就说没有。
- **虚拟屏上坐标点按不可靠**（2026-10-11 实测）：照片网格/无名按钮点不通时，
  改用按名字点（相册卡、楼层行都有 desc），或按例外条款上主屏点。
- **云同步提示条**「正在比对本地和云端数据」是瞬时状态，不是错误；它会占掉顶部一行的位置。
- **冷启动落页不确定**：可能在照片、也可能在相册，先读底部分区哪个高亮（或读标题）再继续。
- **视频与照片的查看器不同**：视频多一个 desc=视频播放器 与中央播放键。

## 验证

- 相册数量：读该相册卡 desc 里的数字（增删前后对比）。
- 恢复：目标从最近删除消失 + 原相册数量增加，两处对账。
- 单张照片：截图为证（先看图再描述，别凭文件名猜内容）。
- 收藏：点后读 `favorite` 的状态变化，并可回「收藏」相册核对数量。

## 危险步骤

> ⚠️ **危险**：以下动作**执行前必须先报出「哪张/哪个相册、多少项」并等主人确认**：
> 1. 查看器里的 **删除**（进「最近删除」，尚有挽回余地）；
> 2. 最近删除里的 **删除**（永久删除，不可恢复）与照片查看器的「更多」里可能出现的彻底删除；
> 3. 「清理建议」里的一键清理（批量删除相似/重复照片，不可逆）；
> 4. 相册详情的 **更换封面**（改变主人自己的相册外观）。
> 删除类操作后要复核两处：目标从当前列表消失 + 相册数量变化。
